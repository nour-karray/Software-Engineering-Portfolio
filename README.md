# Portfolio de Nour El Houda Karray

Portfolio one-page construit avec React, Vite, Framer Motion et React Icons.

## Lancer le projet

```bash
npm install
npm run dev
```

## Compiler

```bash
npm run build
```

Les contenus du portfolio sont centralisés dans
`src/data/portfolioData.js`. Le portrait se trouve dans
`public/images/nour-portrait.webp` et le CV téléchargeable dans
`public/cv-nour-karray.pdf`.
